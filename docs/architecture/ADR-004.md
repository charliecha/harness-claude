## 1. 背景与范围

FR-004 要求新建 `android-llm-app/` 子项目并暴露 GGUF 模型加载接口。当前仓库根是 Python 项目（FastAPI server），Android 子项目独立 Gradle 构建，**不影响 Python 工作流**。

本 ADR 锁定：
- Android 工程结构（Compose 单模块）
- llama.cpp JNI 集成方式（CMake submodule + arm64-v8a 单 ABI）
- Kotlin 侧 `ModelLoader` / `ModelHandle` 抽象与生命周期管理
- 安全边界（路径校验、JNI 边界异常处理）
- 测试分层（单元 + JNI instrumented + smoke）

不涉及（参照 FR-004 §4 排除范围）：推理 API、UI、模型下载、多模型、GPU 后端。

## 3. 核心接口定义

### 3.1 `ModelLoader` 与 `ModelHandle`

```kotlin
package com.harnessclaude.llm.model

import kotlinx.coroutines.CoroutineDispatcher
import kotlinx.coroutines.Dispatchers
import java.io.Closeable

interface ModelLoader {
    /**
     * 从给定路径加载 GGUF 模型。
     * 必须在 IO dispatcher 上调用；主线程调用抛 IllegalStateException。
     */
    suspend fun load(path: String): Result<ModelHandle>
}

class ModelHandle internal constructor(
    private var nativePtr: Long,
    private val sourcePath: String,
) : Closeable {

    val isReleased: Boolean get() = nativePtr == 0L

    /** 仅限 native bridge 内部访问 */
    internal fun nativePointer(): Long {
        check(!isReleased) { "ModelHandle already released (source=$sourcePath)" }
        return nativePtr
    }

    /** 幂等：多次调用仅第一次释放 native 资源 */
    @Synchronized
    fun release() {
        if (nativePtr != 0L) {
            LlamaJni.freeModel(nativePtr)
            nativePtr = 0L
        }
    }

    override fun close() = release()
}

sealed class ModelLoadError(message: String, cause: Throwable? = null)
    : Exception(message, cause) {
    class FileNotFound(path: String) : ModelLoadError("Model file not found: $path")
    class InvalidFormat(path: String) : ModelLoadError("Not a valid GGUF file: $path")
    class UnsafePath(path: String) : ModelLoadError("Path not in app private storage: $path")
    class CalledOnMainThread : ModelLoadError("ModelLoader.load() must not be called on main thread")
    class NativeFailure(reason: String) : ModelLoadError("Native load failed: $reason")
}
```

### 3.2 `LlamaCppModelLoader`（JNI 实现）

```kotlin
package com.harnessclaude.llm.model

class LlamaCppModelLoader(
    private val ioDispatcher: CoroutineDispatcher = Dispatchers.IO,
    private val pathValidator: PathValidator,
) : ModelLoader {

    override suspend fun load(path: String): Result<ModelHandle> = runCatching {
        if (Looper.myLooper() == Looper.getMainLooper()) {
            throw ModelLoadError.CalledOnMainThread()
        }
        withContext(ioDispatcher) {
            pathValidator.requireSafe(path)
            val file = File(path)
            if (!file.exists() || !file.canRead()) {
                throw ModelLoadError.FileNotFound(path)
            }
            val ptr = LlamaJni.loadModel(path, useMmap = true)
            if (ptr == 0L) throw ModelLoadError.NativeFailure("llama_load_model_from_file returned NULL")
            ModelHandle(nativePtr = ptr, sourcePath = path)
        }
    }
}
```

### 3.3 `LlamaJni`（native bridge）

```kotlin
package com.harnessclaude.llm.nativebridge

internal object LlamaJni {
    init { System.loadLibrary("llama_jni") }

    /** 返回 native model 指针；失败返回 0 */
    external fun loadModel(path: String, useMmap: Boolean): Long

    external fun freeModel(nativePtr: Long)

    /** GGUF magic number 校验（轻量，无需加载整个模型） */
    external fun isValidGguf(path: String): Boolean
}
```

### 3.4 `PathValidator`

```kotlin
package com.harnessclaude.llm.storage

class PathValidator(private val allowedRoot: File) {
    private val deniedPrefixes = listOf("/sdcard/", "/data/local/tmp/", "/system/")

    fun requireSafe(path: String) {
        val canonical = File(path).canonicalPath
        if (deniedPrefixes.any { canonical.startsWith(it) }) {
            throw ModelLoadError.UnsafePath(canonical)
        }
        if (!canonical.startsWith(allowedRoot.canonicalPath)) {
            throw ModelLoadError.UnsafePath(canonical)
        }
    }
}
```

### 3.5 `ModelStorage.copyModelFromUri`

```kotlin
package com.harnessclaude.llm.storage

object ModelStorage {
    suspend fun copyModelFromUri(
        context: Context,
        uri: Uri,
        ioDispatcher: CoroutineDispatcher = Dispatchers.IO,
    ): Result<String> = withContext(ioDispatcher) {
        runCatching {
            val modelsDir = File(context.filesDir, "models").apply { mkdirs() }
            val filename = uri.lastPathSegment?.substringAfterLast('/') ?: "model.gguf"
            val target = File(modelsDir, filename)
            try {
                context.contentResolver.openInputStream(uri)!!.use { input ->
                    target.outputStream().use { output ->
                        input.copyTo(output, bufferSize = 8 * 1024 * 1024)
                    }
                }
                target.absolutePath
            } catch (t: Throwable) {
                if (target.exists()) target.delete()
                throw t
            }
        }
    }
}
```

## 5. 技术选型及理由

| 选项 | 决策 | 理由 | 否决的替代方案 |
|------|------|------|----------------|
| LLM runtime | **llama.cpp** (git submodule) | FR 明确要 GGUF；社区生态最成熟；CPU 推理性能 SOTA | MediaPipe LLM Inference（不支持 GGUF）；MLC-LLM（需 TVM 预编译，与 GGUF 生态脱节）；TFLite（LLM 场景弱） |
| ABI | **仅 arm64-v8a** | armv7 32 位地址空间无法承载 1GB+ mmap；x86_64 仅模拟器，不在生产范围 | 全 ABI（APK 体积膨胀 3x，armv7 用户必然 OOM） |
| 加载策略 | **mmap (`llama_model_params.use_mmap = true`)** | 满足 NFR-004-2（JVM 堆 ≤ 50MB）；kernel 按需 page-in；release 后系统自动回收 | 全量 `read`（1GB 模型必 OOM，加载耗时长） |
| Kotlin 异步模型 | **suspend + Dispatchers.IO** | 结构化并发；与 viewModelScope 天然绑定；scope 取消即释放 | Thread + Handler（脆弱）；RxJava（团队不熟）；GlobalScope（gatekeeper 拒绝） |
| Native bridge | **手写 JNI（C++）** | 接口极小（3 个函数）；不需要 codegen | JNA（性能差 10x）；Rust + UniFFI（增加工具链复杂度，本期不必要） |
| UI 框架 | **Jetpack Compose** | 官方推荐；2026 年新项目默认；占位 UI 仅需 50 行 | View + XML（样板代码多） |
| 覆盖率工具 | **Kover** | JetBrains 官方；纯 Kotlin 友好；配置比 Jacoco 简洁 | Jacoco（XML 配置冗长） |
| 静态分析 | **detekt + ktlint** | 与 gatekeeper.sh kotlin pack 对齐 | Android Lint（覆盖 Kotlin 弱） |
| 模型分发 | **应用私有存储 (`filesDir/models/`)** + SAF 拷贝 | 满足 NFR-004-6（路径白名单）；规避 Android 11 Scoped Storage 问题 | 直接读 `/sdcard/`（需 MANAGE_EXTERNAL_STORAGE，审核风险）；assets 全量打包（APK > 1GB） |
| 子项目位置 | **`android-llm-app/` 子目录** | 与 Python 根项目隔离；harness `.workflow-state.json` 仍在仓库根驱动六阶段 | 独立仓库（团队场景下跨仓追踪成本高） |

## 6. 安全边界

### 6.1 入参信任边界

- **`path: String`**：所有外部传入路径必须经过 `PathValidator.requireSafe`
  - `canonicalPath` 化解 `../` symlink 攻击
  - 拒绝 `/sdcard/`、`/data/local/tmp/`、`/system/` 前缀
  - 必须落在 `context.filesDir.canonicalPath` 子树
- **`Uri`**：仅接受 `content://` scheme；不直接 toString 取路径

### 6.2 GGUF 文件完整性

- 调 `LlamaJni.isValidGguf(path)` 校验 magic number（`0x47475546` / "GGUF"），轻量预检
- 完整加密签名校验**不在本 FR 范围**（标记为 TODO-2）

### 6.3 JNI 边界异常处理

- 所有 native 返回值 0 / null 视为失败，包成 `ModelLoadError.NativeFailure`
- 不在 C++ 层抛 C++ 异常穿越 JNI（未定义行为）
- 显式释放：`ModelHandle.release()` 幂等 + `@Synchronized`，避免 double-free

### 6.4 日志安全

- Timber 输出：模型路径 / 加载耗时 / ABI / 文件大小
- **不输出**：模型内容、用户 Uri 原文（可能含个人目录信息）
- 生产构建（release variant）裁剪 verbose 日志

### 6.5 网络边界

- 本 FR 在 `AndroidManifest.xml` **不申请 `INTERNET` 权限**（无需网络）
- 模型来源为本地文件，杜绝中间人篡改

### 6.6 Native 内存边界

- `ModelHandle` 持有 native 指针，scope 取消时 `viewModelScope` 触发 `close()`
- 使用 `@Synchronized` 保护 `release()`，禁止并发释放
- C++ 侧 `llama_free` 由 llama.cpp 保证内部内存清理

## 附录

### A. 风险与降级

| 风险 | 触发条件 | 影响 | 降级策略 |
|------|---------|------|---------|
| Gradle / NDK 构建失败 | NDK 版本不匹配 / submodule 拉取失败 | 本地无法构建 | gatekeeper 跳过 build 但产出明确错误；用户手动安装 NDK 25.1.8937393 |
| 设备内存不足 | 用户加载 7B+ 大模型 | OOM kill | C++ 层加载前调 `sysconf(_SC_AVPHYS_PAGES)` 检查；不足则返回 `NativeFailure("insufficient memory")` |
| llama.cpp upstream 破坏性变更 | submodule 误升级 | JNI 编译失败 | pin commit + CI 每周扫描 upstream changelog |
| mmap 在某些 ROM 失败 | 某些定制 ROM SELinux 策略 | 加载失败 | fallback 到 `use_mmap = false`（仅作为 last resort，会触发 NFR-004-2 失败） |

### B. Rollout 计划

本 FR 是内部基础能力，不涉及上线策略。后续 LLM 用户功能上线时统一规划灰度。
